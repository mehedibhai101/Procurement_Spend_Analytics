# Procurement_Spend_Analytics
I transformed procurement data into a strategic lever for BanglaBazaar by auditing ~40bn BDT in spend. I identified "Process Paralysis" (246-day PO cycle) driving 18.73% Maverick Spend. By designing a vendor risk framework and contract compliance roadmap, I paved the way for ~3.5bn BDT in savings and improved OTIF reliability for IPO readiness.
